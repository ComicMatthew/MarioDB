Baza Danych 3000 - instrukcja dla Windows

1. Wypakuj ten folder na komputer odbierajacy.
2. Uruchom plik: install_for_windows.bat
3. Skrypt utworzy katalog script_files oraz skopiuje wszystkie potrzebne pliki.
4. Uruchom: start_Baza_Danych_3000.bat

UWAGI:
- Wymagany jest Python 3.10+.
- Jesli Python nie jest zainstalowany, zainstaluj go najpierw.
- Potrzebna jest biblioteka openpyxl:
  py -m pip install openpyxl

Jesli na komputerze odbierajacym nie ma git, to nie ma problemu - ten pakiet nie uzywa git.
Jest przygotowany do prostego przeslania jako zip i uruchomienia na Windows.
